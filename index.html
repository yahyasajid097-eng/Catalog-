ربط اللوحة بموقعك

كيف أحصل على المفتاح السري؟
  1. افتح github.com وسجّل الدخول.
  2. اضغط صورة حسابك ثم Settings.
  3. انزل إلى Developer settings ثم Personal access tokens ثم Fine-grained tokens.
  4. اضغط Generate new token وسمّه مثلاً Moon Blossom.
  5. في Expiration اختر أطول مدة.
  6. في Repository access اختر Only select repositories ثم مستودع موقعك فقط.
  7. في Permissions ثم Repository permissions اجعل Contents على Read and write.
  8. اضغط Generate token، وانسخ المفتاح والصقه في الخانة أعلاه.
لا تشارك هذا المفتاح مع أحد، فمن يملكه يستطيع تعديل موقعك.
